# Domain Glossary

## Feedback Loop

- **Course context**: Source material that defines an assignment, such as a
  syllabus, assignment notice, or grading rubric. A team-project notice is
  included only for an assignment explicitly marked as a team project.
- **Feedback record**: An instructor's feedback attached to submitted work,
  kept separate from an AI interpretation of that feedback.
- **Assignment workspace**: The bounded space containing one assignment's
  course context, drafts, reviews, and feedback history.
- **Document role**: Course context, a submission draft, and instructor
  feedback are separate inputs. A document must not be sent in more than one
  role during the same review.
- **Submission review**: A pre-submission inspection of a draft against the
  assignment context and relevant feedback records. It is not a grade
  prediction.
- **Personal insight**: A user-editable strength, improvement area, or repeat
  caution inferred from multiple feedback records and linked evidence.
- **Team context**: Assignment-specific roles, decisions, deadlines, and
  deliverables for a team project. Team context must not be treated as an
  individual's feedback without evidence.
