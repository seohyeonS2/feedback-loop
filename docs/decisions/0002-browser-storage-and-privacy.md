# 0002. 브라우저 저장과 개인정보 경계

## Context

MVP는 계정 없이 공개 데모와 무료 호스팅을 목표로 한다. 과제와 피드백은
개인 학습 기록이므로 서버에 장기 보관하지 않는 편이 안전하다.

## Decision

- 과제, 추출 결과, 피드백 상태, 검토 결과, 사용자가 승인한 인사이트는
  브라우저 IndexedDB에 저장한다.
- JSON 백업·복구를 제공한다. Blob 파일은 백업 JSON 안에서 base64로
  직렬화한다.
- 백엔드는 업로드 요청을 처리하는 동안만 파일을 읽고, 추출된 텍스트와
  검토 요청을 메모리에서 처리한다.
- 문서 추출 직후 주민등록번호·연락처·이메일 패턴을 마스킹하고, 검토와
  인사이트 생성 요청에서도 AI 호출 직전에 동일한 마스킹을 다시 적용한다.
- 프롬프트에는 마스킹된 값을 복원하거나 추측하지 말라는 지시를 추가하되,
  프롬프트만 개인정보 보호 수단으로 사용하지 않는다.
- 이름·주소처럼 문맥에 따라 달라져 결정적으로 탐지하기 어려운 정보는 자동
  마스킹 범위에 포함한다고 보장하지 않고 화면에서 한계를 안내한다.
- 승인 또는 수정된 인사이트만 다음 검토 요청에 재사용한다. 후보·숨김
  상태는 자동 적용하지 않는다.

## Consequences

브라우저를 초기화하거나 다른 기기로 접속하면 데이터가 사라질 수 있으므로
정기적인 JSON 백업이 필요하다. 서버 기반 동기화나 로그인은 향후 별도
보안·보존기간·삭제정책 결정으로 분리한다. 패턴 기반 마스킹은 오탐과 미탐이
가능하므로 새로운 식별자 유형은 테스트를 추가한 뒤 범위를 확장한다.
